## 2. Описание лабораторной работы

Цель работы: изучить принципы реализации базовых методов работы с массивами с использованием колбэков.

В работе были реализованы аналоги методов:

- `forEach`
- `map`
- `filter`
- `find`
- `some`
- `every`
- `reduce`

По условию работы встроенные методы массивов `forEach`, `map`, `filter`, `find`, `some`, `every`, `reduce` не использовались.


## 3. Краткая документация к проекту

Проект состоит из файла `main.js`.

В программе реализованы следующие функции:

printArray(array)

Выводит элементы массива в формате:

Element 0: value 1
Element 1: value 2


printArray1(array)

Выводит элементы массива в формате:

0: 1
1: 2


forEach(array, callback)

Выполняет переданную функцию для каждого элемента массива.

map(array, callback)

Создает новый массив из результатов вызова callback для каждого элемента.

filter(array, callback)

Создает новый массив только из тех элементов, которые подходят под условие.

find(array, callback)

Возвращает первый элемент, который подходит под условие.

some(array, callback)

Проверяет, есть ли хотя бы один элемент, который подходит под условие.

every(array, callback)

Проверяет, подходят ли все элементы массива под условие.

reduce(array, callback, initialValue)

Обрабатывает массив и возвращает одно итоговое значение.


## 4. Примеры использования проекта

Пример массива:

```javascript
const numbers = [1, 2, 3, 4, 5];
```

Пример использования `map`:

```javascript
const squared = map(numbers, function(element) {
    return element * element;
});

console.log(squared);
```

Результат:

```text
[1, 4, 9, 16, 25]
```

Пример использования `filter`:

```javascript
const evenNumbers = filter(numbers, function(element) {
    return element % 2 === 0;
});

console.log(evenNumbers);
```

Результат:

```text
[2, 4]
```

Пример использования `reduce`:

```javascript
const sum = reduce(numbers, function(accumulator, element) {
    return accumulator + element;
}, 0);

console.log(sum);
```

Результат:

```text
15
```

## 5. Ответы на контрольные вопросы

В чем преимущества использования колбэков при работе с массивами?

Колбэки позволяют передавать логику обработки элементов в функцию. Благодаря этому одна функция может работать по-разному в зависимости от переданного callback.

Например, одна и та же функция `filter` может выбирать четные числа, положительные числа или строки нужной длины.

### Какие проблемы могут возникать при использовании колбэков и как их избежать?

Проблемы:

вместо callback передана не функция, что вызывает ошибку;
callback может получать неправильные параметры;
ошибки внутри callback могут нарушить работу программы;
большое количество вложенных callback приводит к сложному и плохо читаемому коду (callback hell).

Как избежать:

проверять, что передан именно тип function;
внимательно передавать аргументы;
добавлять обработку ошибок;
использовать Promise и async/await для упрощения кода.


### Как реализовать функции map, filter, find, some, every и reduce без использования встроенных методов массивов?

Их можно реализовать с помощью обычного цикла `for`, свойства `length`, обращения к элементам массива по индексу и метода `push`.
