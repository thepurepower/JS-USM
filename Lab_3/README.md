
## 1. Инструкции по запуску проекта

1. Скачать проект на компьютер.
2. Открыть папку проекта в IDE (например, Visual Studio Code).
3. Открыть встроенный терминал:
   - Terminal → New Terminal
4. Запустить программу командой:
node script.js

## 2. Описание лабораторной работы

Цель работы: изучить работу с массивами объектов в JavaScript, научиться создавать функции для обработки данных, использовать методы массивов и анализировать информацию.

В ходе выполнения работы были реализованы функции для анализа банковских транзакций.

## 3. Краткая документация к проекту

Программа позволяет выполнять следующие операции:

- получение уникальных типов транзакций;
- вычисление общей суммы транзакций;
- вычисление суммы по определённой дате;
- фильтрация транзакций по типу;
- получение транзакций в диапазоне дат;
- поиск транзакций по магазину;
- вычисление средней суммы транзакций;
- фильтрация по диапазону суммы;
- вычисление суммы дебетовых транзакций;
- поиск месяца с максимальным количеством транзакций;
- определение преобладающего типа транзакций;
- поиск транзакции по ID;
- получение описаний транзакций.

## 5. Ответы на контрольные вопросы

Что такое массив объектов?
Массив объектов — это структура данных, содержащая набор объектов, каждый из которых хранит собственные свойства и значения.

 Для чего используются методы map(), filter(), find()?
- `map()` — создаёт новый массив после обработки элементов;
- `filter()` — выбирает элементы по условию;
- `find()` — находит первый подходящий элемент.

### В чём отличие forEach() от map()?
`forEach()` используется для выполнения действий с элементами массива и ничего не возвращает.
`map()` создаёт и возвращает новый массив.
